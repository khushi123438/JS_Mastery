# JavaScript Zero to Advanced 🚀

A beginner-friendly, step-by-step JavaScript learning repository with explanations, commented examples, practice exercises, output questions, interview Q&A, and mini-project ideas.

## Who is this for?
- Beginners learning JavaScript from scratch
- Students revising core concepts for interviews
- Developers who want a structured quick-reference guide

## How to use this repository
1. Follow the numbered folders in order.
2. Read each topic's `README.md` before running its `.js` file.
3. Predict outputs before executing examples.
4. Complete the practice tasks without looking at solutions first.
5. Explain each concept aloud as interview practice.

## Setup
Install a current [Node.js LTS release](https://nodejs.org/) to run most examples:

```bash
node --version
node 01-introduction/introduction.js
```

Some topics require a browser (DOM, events, and local storage). Open an HTML page in a browser and load the relevant script. Network examples need an internet connection. ES module examples require `.mjs` or `"type": "module"` in `package.json`.

## Suggested weekly plan
- **Week 1:** Topics 01–08 — fundamentals, functions, arrays, objects
- **Week 2:** Topics 09–14 — scope, closures, callbacks, modern syntax
- **Week 3:** Topics 15–20 — browser APIs and asynchronous JavaScript
- **Week 4:** Topics 21–27 — OOP, modules, event loop, storage, regex
- **Week 5:** Topics 28–31 — interview practice, output questions, projects, revision

Adjust the pace to your comfort. Understanding matters more than finishing quickly.
