# Array Methods

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### map
Transforms every item and returns a new array.

### filter
Returns items that pass a test.

### reduce
Combines items into one accumulated result.

### find / some / every
Find one matching item, test whether any match, or test whether all match.

## Run the examples
From the repository root, run `node 13-array-methods/array-methods.js` with a current Node.js installation.

## Interview questions and answers

**Q: map vs filter?**

A: map transforms each element; filter keeps elements that pass a condition.

**Q: What does reduce do?**

A: It combines array values into an accumulated result.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
