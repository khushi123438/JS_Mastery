# Objects

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### Object literals
Objects store related data as key-value properties.

### Read and update
Use dot notation for known property names and bracket notation for dynamic keys.

### Methods
A method is a function stored as an object property.

### Destructuring
Extract selected properties into variables.

## Run the examples
From the repository root, run `node 07-objects/objects.js` with a current Node.js installation.

## Interview questions and answers

**Q: What is an object?**

A: A collection of properties whose keys map to values.

**Q: Dot vs bracket notation?**

A: Bracket notation supports dynamic keys and keys that are not valid identifier names.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
