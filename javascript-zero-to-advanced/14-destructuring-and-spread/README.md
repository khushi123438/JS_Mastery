# Destructuring and Spread

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### Array destructuring
Assign array positions to variables.

### Object destructuring
Extract object properties by key; aliases and defaults are supported.

### Spread syntax
Expand iterable values or enumerable object properties into a new array/object.

### Rest syntax
Collect remaining arguments or properties; spread and rest use the same `...` syntax in different positions.

## Run the examples
From the repository root, run `node 14-destructuring-and-spread/destructuring-spread.js` with a current Node.js installation.

## Interview questions and answers

**Q: What is destructuring?**

A: Syntax for extracting values from arrays or properties from objects.

**Q: Is spread a deep copy?**

A: No. Array/object spread creates a shallow copy.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
