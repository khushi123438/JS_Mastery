# Classes and OOP

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### Class syntax
Classes provide syntax for creating objects with shared methods.

### Constructor
The constructor initializes a newly created instance.

### Inheritance
`extends` creates a subclass and `super()` calls the parent constructor.

### Encapsulation
Private fields use `#`; choose public APIs that protect invariants.

## Run the examples
From the repository root, run `node 21-classes-and-oop/classes.js` with a current Node.js installation.

## Interview questions and answers

**Q: What is a constructor?**

A: A method that initializes a new class instance.

**Q: What does extends do?**

A: It establishes subclassing using JavaScript's prototype-based inheritance.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
