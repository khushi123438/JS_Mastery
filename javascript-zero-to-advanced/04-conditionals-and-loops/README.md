# Conditionals and Loops

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### if / else
Use conditions to choose which block should execute.

### switch
Useful when comparing one expression against several cases; remember `break` unless fall-through is intentional.

### for and while
Use loops to repeat work. Ensure loop conditions eventually become false.

### break and continue
`break` exits a loop; `continue` skips to the next iteration.

## Interview questions and answers

**Q: When use switch?**

A: When one expression is compared against several possible cases.

**Q: break vs continue?**

A: break exits the loop; continue skips to the next iteration.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
