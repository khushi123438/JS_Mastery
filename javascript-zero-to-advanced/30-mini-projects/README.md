# Mini Projects

Build these projects after completing the core topics. Each is a guided project rather than a finished production application.

## 1. Calculator
**Practise:** functions, DOM, events, input validation.
- Create a numeric display and buttons for digits and operations.
- Handle divide-by-zero and invalid expressions safely.
- Add keyboard support and tests for edge cases.

## 2. Todo App
**Practise:** arrays, objects, DOM, events, local storage.
- Add a task, mark it complete, and delete it.
- Persist tasks in local storage.
- Add filters: all, active, completed.

## 3. Quiz App
**Practise:** arrays of objects, conditional rendering, score tracking.
- Store questions and answer choices as data.
- Show feedback after each answer.
- Display a final score and restart option.

## Suggested file layout
Create `index.html`, `style.css`, and a dedicated JavaScript file for each browser app as you implement it. Keep DOM code in the browser environment.

## Interview reflection
For each project, be ready to explain the data model, event flow, edge cases, and one improvement you would make next.
