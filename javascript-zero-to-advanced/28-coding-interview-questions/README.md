# Coding Interview Questions

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### Problem-solving process
Clarify inputs/outputs, discuss edge cases, choose an approach, then analyze time and space complexity.

### Arrays and strings
Practise frequency maps, two pointers, sliding windows, and string traversal.

### Correctness
Test empty inputs, one-element inputs, duplicates, and boundary values.

### Complexity
Explain how runtime and extra memory grow with input size.

## Run the examples
From the repository root, run `node 28-coding-interview-questions/solutions.js` with a current Node.js installation.

## Practice exercises
- [ ] Implement palindrome checking.
- [ ] Find duplicates in an array and state complexity.

## Interview questions and answers

**Q: What should an interview solution include?**

A: Approach, correctness reasoning, complexity, code, and edge cases.

**Q: Why discuss complexity?**

A: It explains how time and memory needs scale with input size.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
