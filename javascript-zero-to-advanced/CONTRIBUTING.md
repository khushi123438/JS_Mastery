# Contributing

Thanks for helping improve JavaScript Zero to Advanced!

## Contribution guidelines
1. Keep explanations beginner-friendly and technically accurate.
2. Add runnable examples with meaningful comments and expected output where possible.
3. State whether an example requires Node.js, a browser, or network access.
4. Include practice questions and answers/explanations when adding a concept.
5. Avoid committing secrets, credentials, large generated files, or `node_modules`.
6. Prefer small commits with clear messages.

## Suggested topic README sections
- Learning objectives
- Concept explanation
- Syntax and examples
- Common mistakes
- Practice exercises
- Interview questions with answers
- Further learning

## Before opening a pull request
- Run Node.js examples where applicable.
- Check spelling, formatting, and output comments.
- Confirm links and folder names are correct.
