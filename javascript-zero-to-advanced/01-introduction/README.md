# Introduction to JavaScript

## Learning objectives
By the end of this topic, you should be able to explain the key concepts, read the examples, and solve basic problems independently.

## Concepts

### What is JavaScript?
JavaScript is a programming language used to add behavior and interactivity to websites. It also runs on servers and in other environments.

### Where does it run?
Browsers provide a JavaScript engine and browser APIs. Node.js runs JavaScript outside the browser and provides server-side APIs.

### JavaScript vs Java
They are different languages with different ecosystems; the similar names do not mean they are the same language.

### How to run examples
Open browser DevTools Console, or install Node.js and run `node introduction.js`. Browser-only APIs such as `document` require a browser page.

## Run the examples
From the repository root, run `node 01-introduction/introduction.js` with a current Node.js installation.

## Interview questions and answers

**Q: What is JavaScript?**

A: A high-level programming language used for interactive web experiences and many other environments.

**Q: Is JavaScript the same as Java?**

A: No. They are distinct languages with different designs and ecosystems.

## Common mistakes
- Memorizing syntax without understanding the output.
- Ignoring empty inputs, missing values, and error cases.
- Confusing browser APIs with Node.js APIs.
- Assuming object/array spread makes a deep copy.
